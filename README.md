# 三國小軍師：合作守村

結合三國 Q 版武將與國小複習題目的 Godot 戰棋遊戲。

[開始遊戲](https://ding0502-star.github.io/sanguo-learning-tactics/)

## 遊戲玩法
每回合先答兩題，再操作劉備、關羽、張飛移動、攻擊或施放技能。答對得到 2 計策點，答錯得到 1 點並閱讀解析；守住村莊五回合或击退全部敵軍即可獲勝。

支援滑鼠、觸控、全螢幕。建議使用電腦或橫向平板。學習紀錄保存在各自瀏覽器，沒有跨裝置同步。

## 專案內容
- `game/`：Godot 4.6 原始碼、美術、字型與 30 題社會三年級「合作與競爭」題庫。
- `docs/`：已匯出的網頁遊戲，由 GitHub Pages 發布。
- `docs/licenses/`：Godot 與字型授權。

## 開發與匯出
安裝 Godot 4.6，開啟 `game/project.godot`。安裝對應匯出範本，Web 預設使用單執行緒；匯出到 `docs/index.html` 後提交更新。請透過 HTTP 網站開啟遊戲，不要直接雙擊 HTML。

## 驗證
已在 Chrome 驗證載入、中文字型、答題計分、移動、敵軍回合、技能、重新整理保留紀錄、全螢幕、1024×768 縮放與模擬觸控。尚未實機驗證 iPad Safari。

原始 Word 題庫與本機工具未包含於此儲存庫。題目保留來源識別；第三方字型、引擎依各自授權，題庫不另行授予轉授權。
